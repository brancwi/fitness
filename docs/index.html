📲 Installation

  1. Télécharge l'APK via le bouton ci-dessus ou scanne le QR code.
  2. Ouvre le fichier téléchargé sur ton téléphone.
  3. Si demandé, autorise l'installation depuis ce navigateur/fichier.
  4. L'application s'installe par-dessus l'ancienne version sans perdre tes données.
⚠️ Pour les mises à jour, réinstalle simplement le nouvel APK. Ta base de données (historique, séances, mensurations) est conservée automatiquement.
